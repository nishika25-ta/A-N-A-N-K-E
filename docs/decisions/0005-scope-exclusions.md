# ADR-0005: MVP scope exclusions

Excluded from v0.1: real endpoints, services, credentials or personal data; shell, browser or network tools; multi-tenancy, RBAC or SaaS; distributed ledgers or blockchain; vector stores; Kubernetes, Redis, Kafka; a Rust rewrite; fine-tuning or GPUs; production certification; signed receipts and external anchors (future work); prefix or wildcard resource scopes; remote-effect atomicity. Any addition needs a measured need and a new ADR.
