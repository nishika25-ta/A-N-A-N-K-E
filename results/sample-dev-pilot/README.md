# Sample: dev-split engineering pilot (run-726411f5f841)

**What this is:** the metrics and manifest of `uv run ananke bench run --config research/experiments/pilot-dev.json --offline`.
It covers 36 dev scenarios × 108 conditions = 6,480 checkpoint records. The full `checkpoints.jsonl` is regenerable and gitignored.

**What this is not:** evidence about LLM behaviour, a holdout result, or a preregistered test. The agent is the
deterministic belief agent and the summarizer is a declared synthetic stress model (ADR-0011). The holdout
split is locked until `research/preregistration.md` is FROZEN.

Rendered tables: `research/pilot-dev-report.md` (generated by `research/experiments/render_report.py`).
